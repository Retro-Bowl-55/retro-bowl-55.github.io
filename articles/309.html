How to approach P.Craft

Start by gathering enough wood to use the workbench and make a sword. The PICO-8 action buttons have separate jobs for handling the menu and using the item you equipped, so check the selected slot if a tool doesn't respond as expected.

Learn a route between your workbench and the nearby trees before exploring much farther. Gathering on a familiar loop makes it easier to finish a recipe and return with a useful tool when you encounter something you couldn't deal with earlier.
