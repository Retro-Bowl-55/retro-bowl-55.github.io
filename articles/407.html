How to approach OvO Dimensions

Use the arrow keys to get a feel for the stick figure's stopping distance on a broad platform. When you jump into a narrow landing, release the horizontal input as you approach it so the next obstacle doesn't catch you while you're still moving.

On a difficult room, mark the last flat surface you can reach reliably. Set up the next jump from that spot until the route is consistent. Then try to connect the two movements without stopping if you're aiming for a faster clear.
