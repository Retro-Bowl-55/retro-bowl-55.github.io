How to approach Adventure Drivers

Car Racing · Practice notes for Adventure Drivers

The catalog lists Space for this action: Jump. Try it at the start of a run so you can see how it responds.

Look for a clear line through a corner or narrow section. Adjust speed before you enter so you have time to make a correction.

If the same obstacle stops several runs, change the approach speed while keeping the same route. That helps you see whether speed is causing the problem.
