How to approach Generic Fishing Game

Treat the wait for a bite and the struggle after it as different parts of the catch. Watch which cue tells you a fish is actually on the line before trying to reel in. Pulling in too early can end the attempt before it starts.

Read the movement prompt once the fish is hooked. Focus on what the game wants you to do next instead of continuing the input that started the catch. If the fish escapes, compare the last prompt with the input you used and adjust on the next cast.
