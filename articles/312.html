How to approach Terraira

Before exploring below ground, test how the 2D world responds to placing and breaking a block. Start a short tunnel with a clear return route so you can get back to the surface after gathering anything new.

Leave some building material available for climbing rather than using every block while setting up. In a deep shaft, small shelves make an easy way out and give you places to stop while you adjust the next part of the route.
